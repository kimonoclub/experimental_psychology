データが語る「嘘」を見抜く
―相関の基礎から疑似相関・因果関係・偏相関の計算まで―

本テキストは、第6回目の心理学実験の授業を休んだ人が、「相関分析の基礎」「疑似相関（見かけ上の相関）の仕組み」「因果関係の成立条件」「偏相関分析の意味と計算方法」について、イチから論理的に理解できるように作成されたフォロー教材です[cite: 1, 2]。

1. 相関分析の基礎（復習）

（1）相関関係と因果関係の違い

■ 相関関係（Correlation）

2つの現象（変数 $A$ と $B$）の間に「片方が変化すると、もう片方も連動して変化する」という直線的な関係があること（範囲：$-1.0 \sim +1.0$）[cite: 1, 2]。

  • 正の相関： $A$ が高いほど、$B$ も高い[cite: 1, 2]。
  • 負の相関： $A$ が高いほど、$B$ は低い[cite: 1, 2]。

■ 因果関係（Causality）

一方の変数（原因）が、もう一方の変数（結果）を直接変化させている関係[cite: 1, 2]。

⚠️ 重要ポイント：「相関関係があるからといって、因果関係があるとは限らない」[cite: 1, 2]

2. 疑似相関（見かけ上の相関）とは？

（1）疑似相関（Spurious Correlation）の定義

一見すると変数 $X$ と変数 $Y$ の間に強い相関関係があるように見えても、実は共通する「第三の変数 $Z$」が存在しており、$X$ と $Y$ の間には直接的な因果関係が全く存在しない（または極めて弱い）状態を「疑似相関（見かけ上の相関）」と呼びます[cite: 1, 2]。

（2）日常に潜む具体例

授業で扱った具体的な事例を見てみましょう[cite: 1, 2]。

📌 事例1：夜間照明と子どもの近視（Quinn et al., 1999）[cite: 1, 2]

見かけ上の相関： 夜、部屋の照明をつけて寝る子どもほど、近視になりやすい（暗い部屋: 10% / 豆電球: 34% / 明るい部屋: 55%）[cite: 1, 2]。

$\rightarrow$ 誤った結論：「夜間照明が近視の原因だ！」[cite: 1, 2]

隠れた真犯人（第三の変数 $Z$）：「両親が近視かどうか（遺伝傾向）」[cite: 1, 2]

メカニズム： 近視の両親は夜間に部屋を明るくする傾向があり、同時に遺伝によって子どもも近視になりやすい。照明と近視の間に直接の因果関係はなかった（Zadnik et al., 2000）[cite: 1, 2]。

📌 事例2：アイスクリームの売上と水難事故[cite: 1, 2]

見かけ上の相関： アイスの売上が増えると、水難事故（プールや海での事故）が増える[cite: 1, 2]。

隠れた真犯人（$Z$）：「気温 / 季節（夏であること）」[cite: 1, 2]

メカニズム： 気温が高い（夏である）からアイスが売れ、同時に気温が高いから海やプールに行く人が増えて事故が増える[cite: 1, 2]。

📌 事例3：靴のサイズと読解力[cite: 1, 2]

見かけ上の相関： 靴のサイズが大きい子どもほど、読解力テストの点数が高い[cite: 1, 2]。

隠れた真犯人（$Z$）：「年齢 / 発達段階」[cite: 1, 2]

メカニズム： 年齢が上がる（成長する）ほど足が大きくなり、同時に読解力も身につく[cite: 1, 2]。

📌 事例4：外国人の割合とコロナ罹患率（沖縄県の例）[cite: 1, 2]

見かけ上の相関： 外国人の割合が高い地域ほど、コロナ罹患率が高い[cite: 1, 2]。

隠れた真犯人（$Z$）：「人口密度 / 都市化の程度（または基地周辺の人口動態）」[cite: 1, 2]

3. 疑似相関かどうかをどう論理的に導くか？

データ（相関係数 $r$）を見たときに、それが「本物の関係」なのか「疑似相関」なのかを見抜くためには、理論的・論理的な思考プロセスが必要です[cite: 1, 2]。

🔍 疑似相関を見ぬく3つのチェックリスト[cite: 1, 2]

1. メカニズムの妥当性を疑う： 「$X$ が $Y$ を変化させる直接的な物理的・心理的メカニズムは説明できるか？」と問いかける（例：電気をつけただけで目の眼球の形が変わるのか？ $\rightarrow$ 生理学的に不自然）[cite: 1, 2]。

2. 共通の原因（第三の変数 $Z$）を探す： 「$X$ と $Y$ の両方に同時に影響を与えるような背景（年齢、性別、季節、地域、遺伝、経済状況など）はないか？」を考える[cite: 1, 2]。

3. 統計的に $Z$ を取り除いて（固定して）再分析する： 第三の変数 $Z$ の影響を数式上で「引き算」したあとも、$X$ と $Y$ の関係が残るかを確認する（これが後述の偏相関分析）[cite: 1, 2]。

4. 因果関係を主張するための3つの必須条件

心理学や科学において、単なる相関ではなく「$X$ が原因で $Y$ が結果である（因果関係がある）」と主張するためには、以下の3つの条件をすべて満たす必要があります[cite: 1, 2]。

【因果関係の3条件】[cite: 1, 2]

① 共変関係（相関の存在）： $X$ と $Y$ が連動して変化していること[cite: 1, 2]。

② 時間的先後関係： 原因 $X$ が「先」に起こり、結果 $Y$ が「後」に生じること[cite: 1, 2]。

③ 他要因（$Z$）の排除： 第三の変数 $Z$（剰余変数）の影響がすべて否定されていること[cite: 1, 2]。

なぜ相関分析だけでは不十分なのか？
相関係数 $r$ を計算しただけでは、条件①（共変関係）しか証明できていません[cite: 1, 2]。時間の前後関係（どちらが原因か）が不明であり、第三の変数 $Z$ による疑似相関の可能性（条件③）が残るため、相関＝因果と結論づけるのは科学的エラー（誤謬）となります[cite: 1, 2]。

5. 偏相関（Partial Correlation）とは？

（1）偏相関のコンセプト

相関係数 $r_{xy}$ だけでは、第三の変数 $Z$ による「汚染」を防げません[cite: 1, 2]。 偏相関分析（Partial Correlation Analysis）とは、数式を用いて「第三の変数 $Z$ の影響を統計的に取り除き（一定にコントロール・固定し）、純粋な $X$ と $Y$ だけの間の関連性」を抽出する手法です[cite: 1, 2]。

・通常の相関 $r_{xy}$： $Z$ の影響が含まれた「見かけの相関」[cite: 1, 2]。

・偏相関係数 $r_{xy \cdot z}$： $Z$ の影響を引き算・消去した「純粋な相関」[cite: 1, 2]。

（2）偏相関の計算方法と数式

$X$（変数1）、$Y$（変数2）、$Z$（コントロールしたい第三の変数）の3つの変数があるとき、各ペアの通常の相関係数を $r_{xy}, r_{xz}, r_{yz}$ とします[cite: 1, 2]。

このとき、$Z$ の影響を除外した $X$ と $Y$ の偏相関係数 $r_{xy \cdot z}$ の公式は以下の通りです[cite: 1, 2]。

$$r_{xy \cdot z} = \frac{r_{xy} - r_{xz} r_{yz}}{\sqrt{1 - r_{xz}^2} \sqrt{1 - r_{yz}^2}}$$

💡 数式の意味：

・分子 ($r_{xy} - r_{xz} r_{yz}$)： 元の相関 $r_{xy}$ から、「$Z$ を経由して生じている見かけ上の影響（$r_{xz} \times r_{yz}$）」を引き算しています[cite: 1, 2]。

・分母 ($\sqrt{1 - r_{xz}^2} \sqrt{1 - r_{yz}^2}$)： $X$ と $Y$ それぞれから「$Z$ によって説明できる部分」を取り除いたあとの、残りのばらつきの大きさを揃えて標準化しています[cite: 1, 2]。

（3）授業での実習事例：コーヒー売上の謎（資料5）

授業では「気温が高くなると、コーヒーは売れなくなるのか？」というデータを検証しました[cite: 1, 2]。

■ 測定データと通常の相関係数[cite: 1, 2]

・$X$（気温）と $Y$（コーヒー売上）の相関： $r_{xy} = -0.22$ （負の相関：気温が上がるとコーヒーが売れない？）[cite: 1, 2]

・$X$（気温）と $Z$（日照時間）の相関： $r_{yz} = 0.51$[cite: 1, 2]

・$Z$（日照時間）と $Y$（コーヒー売上）の相関： $r_{xz} = -0.16$[cite: 1, 2]

■ 偏相関の計算（日照時間 $Z$ の影響を除外）[cite: 1, 2]

$$r_{xy \cdot z} = \frac{-0.22 - (-0.16 \times 0.51)}{\sqrt{1 - (-0.16)^2} \sqrt{1 - 0.51^2}} \approx -0.16$$

■ Excelでの入力式[cite: 1, 2]

=(-0.22 - (-0.16 * 0.51)) / (SQRT(1 - (-0.16)^2) * SQRT(1 - 0.51^2))

■ 考察・解釈[cite: 1, 2]

・分析前（$r = -0.22$）： 「気温が高いとコーヒーが売れない」という強い負の印象[cite: 1, 2]。
・偏相関分析後（$r_{xy \cdot z} = -0.16$）： 「日照時間（晴れの日）」の影響を取り除くと、負の相関は弱まった[cite: 1, 2]。

結論： 最初の相関には、「日差しが強くて暑い日は冷たい飲料が好まれる」という日照時間による見かけ上の影響が混ざっていました[cite: 1, 2]。偏相関を使うことで、データの「見た目上の嘘」に騙されずに済むようになります[cite: 1, 2]。
