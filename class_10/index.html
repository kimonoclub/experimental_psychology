第10回 フォローアップ・学習テキスト

アンケートデータのクリーニングから
仮説検証（得点化・群分け・相関分析）までの一連の実践

本テキストは、第10回目の心理学実験の授業で実施した「収集したアンケートデータの実際の分析プロセス」について、各手順の必要性（理由）と具体的な計算方法（Excel関数）を分かりやすく解説したフォロー教材です[cite: 1, 2]。

1. 今回のデータ分析の全体フロー

今回の授業では、実際にGoogleフォーム等で収集したアンケートデータを用い、以下の4つのステップでデータ分析を進めました[cite: 1, 2]。

Step 1 データのクリーニング（欠損値・不注意回答の除外）[cite: 1, 2]
Step 2 得点化（尺度項目の合計値算出）[cite: 1, 2]
Step 3 調整変数（自己効力感）による群分け（中央値分割）[cite: 1, 2]
Step 4 群ごとの相関分析（仮説の検証と考察）[cite: 1, 2]

2. 【Step 1】データのクリーニング（無効データの除外）

なぜこの手順が必要か？（理由）

アンケート調査で得られた生データには、回答の途中で諦めてしまった「欠損値（空欄）」を含むデータや、設問文を読まずにすべて同じ数字を選んだり適当に回答したりした「不注意回答（ノイズ）」が含まれています[cite: 2, 3]。

こうした無効データを残したまま分析を行うと、平均値や相関係数が歪み、間違った結論（研究のエラー）を導いてしまうため、分析前に「データのクリーニング（掃除）」を行うことが必須となります[cite: 2, 3]。

具体的な処理方法

■ 欠損値の削除

必須項目に回答漏れがある行（参加者）をデータから削除します[cite: 2]。

■ IMC（Instructional Manipulation Check）項目の確認

調査に紛れ込ませた「データ処理の都合上、この項目では『あてはまらない（1）』を選択してください」という質問を確認します[cite: 2, 3]。

ここで「1」以外の数値（2〜4）を選んでいる回答者は、質問文を読まずに回答したと判断し、データから削除します[cite: 2, 3]。

3. 【Step 2】得点化（変数の合計値の算出）

なぜこの手順が必要か？（理由）

心理学では、1つの心の概念（例：地震への備え）を1つの質問だけで測ると誤差が大きくなるため、複数の質問項目（例：3〜6項目）で多角的に測定します[cite: 2, 3]。分析を行うには、これら複数の項目の回答を1つにまとめた「代表値（合計点または平均点）」を計算して、「その人の備えの高さ」「その人の脅威感の強さ」として数値化（得点化）する必要があります[cite: 2, 3]。

計算方法（Excelでの関数）

それぞれの構成概念に対応する項目の数値を足し合わせます[cite: 2]。

■ 独立変数（$X$）：脅威得点（4項目の合計）[cite: 2]

=SUM(L2:O2)

■ 調整変数（$M$）：自己効力感得点（4項目の合計）[cite: 2]

=SUM(P2:S2)

■ 従属変数（$Y$）：備え得点（6項目の合計）[cite: 2]

=SUM(F2:K2)

4. 【Step 3】調整変数（自己効力感）による群分け

なぜこの手順が必要か？（理由）

今回の研究仮説は、「地震への脅威感（恐怖）が備え行動に与える影響は、自己効力感（自分にも備えができるという自信）の高さによって変わる（調整される）」というものです[cite: 2]。

本来、調整効果は高度な「交互作用分析（重回帰分析）」を用いて一度に計算しますが、今回は基礎的な分析手法として、自己効力感の高さでデータを「高群」と「低群」の2つに分割し、それぞれの群で『恐怖 $\rightarrow$ 行動』のつながりの強さを比較する手法をとります[cite: 2]。

計算方法（中央値の算出と並び替え）

1. 中央値（Median）の算出[cite: 2]

全員の「自己効力感得点」の真ん中の値（中央値）を求めます[cite: 2]。

=MEDIAN(自己効力感得点の範囲)

2. データの並び替えと2群分割[cite: 2]

Excelの「並べ替え」機能を使って、「自己効力感得点」を昇順（小さい順）に並べ替えます[cite: 2]。

  • 中央値以下のグループ： 「自己効力感 低群」[cite: 2]
  • 中央値を超えるグループ： 「自己効力感 高群」[cite: 2]

※分かりやすいように、2つの群の間にExcel上で数行の空行をあけておきます[cite: 2]。

5. 【Step 4】群ごとの相関分析と考察

なぜこの手順が必要か？（理由）

分けた2つのグループごとに、「脅威得点（恐怖）」と「備え得点（行動）」の間の相関係数（$r$）を計算します[cite: 2]。これにより、「自信がある人（高群）」と「自信がない人（低群）」とで、恐怖心が行動を促すパイプの太さ（相関の強さ）に違いがあるかを直接確かめることができます[cite: 2]。

計算方法（Excelでの関数）

■ 高群における相関係数[cite: 2]

=CORREL(高群の脅威得点範囲, 高群の備え得点範囲)

■ 低群における相関係数[cite: 2]

=CORREL(低群の脅威得点範囲, 低群の備え得点範囲)

【重要】分析結果の解釈と考察のやり方

今回は受講生から集めたデータであり、1グループあたりのサンプルサイズ（人数）が比較的小さいため、統計的有意性（$p$ 値）の白黒判定は行わず、相関係数（$r$）の値とその符号（方向性）に着目して考察を行いました[cite: 2]。

■ 仮説とデータが整合的（一致）と言えるパターン例[cite: 2]

・自己効力感 高群： $r = .35$ 程度（正の相関：危機感が高まるほど、しっかり備え行動をとる）[cite: 2, 3]
・自己効力感 低群： $r = .10$ や負の値（無相関〜負の相関：いくら恐怖を感じても、自分には無理だと思って行動しない）[cite: 2, 3]

もしこのような結果が得られれば、「自己効力感が低い人は、単に恐怖を煽るだけでは防災行動を起こさない」という保護動機理論の予測と整合的であると考察できます[cite: 2, 3]。
