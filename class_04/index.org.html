ミュラー・リヤー錯視における
矢羽の角度効果と統計分析・レポート執筆の実践

本テキストは、第4回目の心理学実験の授業を休んだ人が、授業で実施した「実験の内容」「理論的背景」「統計量の算出方法と意味」「条件間の差の検討方法（$t$検定と多重比較）」および「レポートの書き方」を網羅的に学習できるように作成されたフォロー教材です[cite: 1, 2]。

1. 今回の授業で実施したことの全体像

第4回の授業では、主に以下の4つのステップを実施・学習しました[cite: 3]。

■ 実習実験の実施

ミュラー・リヤー錯視図形を用い、「矢羽の角度（30度・45度・60度）」を変えることで、主直線に対する錯視量（px）がどのように変化するかを調整法によって測定しました。

■ 仮説と結果の予測

知覚心理学におけるグレゴリー（Gregory）の「奥行き仮説（不適切な恒常性スケーリング説）」に基づき、なぜ矢羽の角度によって錯視量が変化するのかという理論的メカニズムと予測を整理しました。

■ 統計数値の算出と意味の復習

取得した実験データから、各条件の平均値（Mean, $M$）、標準偏差（Standard Deviation, $SD$）、95%信頼区間（95% Confidence Interval, 95% CI）を算出し、それぞれの数値が持つ意味を再確認しました。

■ 条件間の差の検討と多重比較の処理

3つの角度条件間に有意な差があるかを調べるため、対応のある$t$検定を実施しました。その際、複数回の検定を繰り返すことで生じる「多重比較の危険性（第1種の過誤の蓄積）」と、その対処法である「ボンフェローニ（Bonferroni）法」を学びました。

2. 理論的背景と実験結果の予測

（1）グレゴリーの「奥行き仮説（不適切な恒常性スケーリング説）」とは？

私たちは平面（二次元）の図形を見るときでも、脳が無意識のうちに「三次元の空間構造（奥行き）」として解釈・マッピングしようとする適応的仕組みを持っています。

・外向きの矢羽（＜―＞）： 建物の外側の角（凸構造：手前に出っ張っている）として処理される。

・内向きの矢羽（＞―＜）： 部屋の隅の角（凹構造：奥に引っ込んでいる）として処理される。

網膜上に映る直線の長さ（二次元の像）が同じであっても、脳が「奥にある（遠くにある）」と判断した対象に対しては、「遠くにあるのにこの大きさで見えるなら、実際はもっと大きいはずだ」と不適切に恒常性補正（拡大補正）を行います。これが錯視の発生要因です。

（2）矢羽の角度による錯視量の予測

この奥行きマッピングの仕組みを考えると、矢羽の角度が鋭角（角度が小さく）になるほど、図形が示す三次元構造の奥行き勾配（急さ）は強く知覚されます。したがって、脳による拡大補正量（錯視量）も増大すると予想されます。

予測される錯視量の順序： 30度条件 ＞ 45度条件 ＞ 60度条件

（※角度が小さくなるほど、錯視量は大きくなる）

3. 実験手法とデータ処理

実験では、標準刺激（矢羽つき直線）と等しい長さに感じるように比較刺激（直線のみ）を参加者自身がマウス操作で合わせる「調整法」を採用しました。

・主観的等価点（PSE）： 参加者が「同じ長さだ」と判断した比較刺激の平均値。

・錯視量（px）の算出式： $\text{錯視量} = \text{PSE（主観的等価点）} - \text{標準刺激の物理的長さ}$

また、提示順序による「疲労効果」や「練習効果」を防ぐためにカウンターバランス（ラテン方格法）を用い、調整の開始位置による影響を防ぐために「上昇系列（短 $\rightarrow$ 長）」と「下降系列（長 $\rightarrow$ 短）」を同回数ずつ実施しました。

4. 基礎統計量の算出方法とその意味

実験データから各角度条件の傾向を把握するために算出した3つの指標（記述統計）について復習します。

① 平均値（Mean, $M$）

算出方法：全員の錯視量の合計をサンプルサイズ（有効参加者数 $N$）で割る。

心理学的な意味： その条件における「集団としての代表的な錯視の大きさ」を表します。

② 標準偏差（Standard Deviation, $SD$）

算出方法：各データの偏差（個人の値 $- M$）を二乗して合計し、不偏分散とするために $N-1$ で割った値の平方根をとる。

心理学的な意味： データの「ばらつき（個人差）の大きさ」を表します。$SD$ が小さいほど、参加者全員が似たような錯視量を示した（個人差が少ない）ことを意味します。

③ 95%信頼区間（95% Confidence Interval, 95% CI）

算出方法：標準誤差 $SE = \frac{SD}{\sqrt{N}}$ を求め、$t$ 分布の限界値を用いて $\text{95\% CI} = [M - t_{.025} \times SE, M + t_{.025} \times SE]$ で算出。

心理学的な意味： 「同じ実験を100回繰り返した際、95回はその区間の中に母集団の真の平均値が含まれる」という推定の信頼範囲を示します。

グラフでの見方： 2つの条件の95%信頼区間のエラーバーが大きく重なっていない場合、母集団においても条件間に明確な差が存在する可能性が高いという視覚的目安になります。

授業で集計した有効データ（$N=21$）の統計量は以下の通りです。

5. 条件間に「差がある」と言えるか？（推測統計と $t$ 検定）

平均値に数値上の差（30.8 vs 25.6 vs 16.2）が見られても、それが「たまたま実験の参加者のクセで生じた偶然の差」なのか、「矢羽の角度という条件の違いによって必然的に生じた本質的な差（有意差）」なのかを判定する必要があります。

■ 対応のある $t$ 検定（Paired-samples t-test）

今回は同一の参加者が3つの角度条件（30度・45度・60度）すべてを体験している（参加者内計画）ため、個人差の影響を取り除いて比較できる「対応のある $t$ 検定」を使用します。

・帰無仮説 ($H_0$)：「条件間に差はない（差は0である）」

・対立仮説 ($H_1$)：「条件間に差がある」

・$p$ 値（有意確率）：帰無仮説が正しいと仮定したときに、偶然このような大きな差が得られる確率。一般に $p < .05$（5%未満）であれば帰無仮説を棄却し、「統計的に有意な差がある」と判断します。

6. 多重比較の危険性とボンフェローニ（Bonferroni）法

ここが今回の講義で最も重要な統計的ポイントです。

多重比較の危険性（第1種の過誤の膨らみ）

「本当は差がないのに、誤って『差がある』と判定してしまうエラー」を第1種の過誤（$\alpha$ エラー）と呼びます。通常、1回の $t$ 検定を行う際の有意水準は $\alpha = .05$（5%）に設定します。

しかし、今回の実験には3つの条件（30度・45度・60度）があるため、ペアの組み合わせは以下の3パターン存在します：

1) 30度 vs 45度

2) 45度 vs 60度

3) 30度 vs 60度

もし、この3ペアに対して「有意水準 $\alpha = .05$ の通常の $t$ 検定」を3回繰り返すとどうなるでしょうか？ 検定を繰り返すごとにエラーを起こす確率が蓄積され、全体として少なくとも1回誤った判断を下してしまう確率（Familywise Error Rate）は、以下のように膨らんでしまいます：

$\text{全体のエラー率} = 1 - (1 - .05)^3 \approx 14.3\%$

つまり、5%に抑えているつもりだったエラー率が、約14.3%まで跳ね上がってしまう（多重比較の危険性）のです。

対処法：ボンフェローニ（Bonferroni）補正

このエラー率の膨らみを防ぐ最もシンプルな方法がボンフェローニ法です。

・補正の仕組み： 全体のエラー率を5%（.05）以内に収めるために、1回あたりの検定で用いる基準（有意水準）を検定回数（$k=3$）で割って厳しくします。

調整後の有意水準 $\alpha' = \frac{.05}{3} \approx .0167 \ (\approx .016)$

・判定ルール： 各ペアの $t$ 検定で得られた $p$ 値が .016（または .0167）未満 であった場合のみ、「統計的に有意な差がある」と判定します。

7. 実験データ分析結果とレポート記述例

実際に算出された数値を用いて、結果をレポートの「結果（Results）」セクションに記述するフォーマット例です。

【実際の分析結果（自由度 $df=20$）】

・30度条件 vs 45度条件：t(20) = 2.68, p = .015 → p = .015 < .016 であるため、有意差あり。

・45度条件 vs 60度条件：t(20) = 5.98, p < .001 → p < .016 であるため、有意差あり。

・30度条件 vs 60度条件：t(20) = 7.81, p < .001 → p < .016 であるため、有意差あり。

【レポート形式の記述例】

矢羽の角度条件による錯視量の違いを検討するため、対応のある $t$ 検定を行った。なお、多重比較による1種の過誤を防ぐため、ボンフェローニ法を用い、有意水準を $\alpha = .016$ に調整した。

分析の結果、30度条件（$M = 30.8, SD = 12.9$）は45度条件（$M = 25.6, SD = 9.1$）よりも有意に錯視量が大きかった（$t(20) = 2.68, p = .015$）。また、45度条件は60度条件（$M = 16.2, SD = 11.0$）よりも有意に錯視量が大きかった（$t(20) = 5.98, p < .001$）。さらに、30度条件と60度条件の間においても有意な差が認められ、30度条件の方が錯視量が大きかった（$t(20) = 7.81, p < .001$）。

以上の結果から、矢羽の角度が小さく（鋭角に）なるほど、錯視量が有意に増加することが示された。

8. 考察（Discussion）の執筆ガイドライン

レポートの考察セクションでは、以下の流れに沿って論理を展開します。

1. 結果の要約と仮説の検証

「矢羽の角度が小さくなるほど錯視量が増加する」という実験結果が得られ、冒頭で立てた仮説（30度 ＞ 45度 ＞ 60度）が支持されたことを述べる。

2. 理論的解釈（グレゴリーの奥行き仮説との結びつけ）

鋭角な矢羽ほど、脳はそれを「より深い奥行き構造」として空間マッピングしたため、視覚システムによる拡大補正（不適切な恒常性スケーリング）が強く働いたと解釈できることを論じる。

3. 今後の課題・限界

本実験では30度〜60度の範囲で検討したが、より極端な角度（例：15度や75度以上）や、直線・矢羽の長さを変化させた場合の検討が必要であることを提示する。
